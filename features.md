# Current Features (Web)

- Shopping list CRUD: add, edit, delete, and toggle completed items.
- Categories per item with category selector and category pills on each item.
- Quick-add chips for common items.
- Filters: category chips, hide-completed toggle, and live text filtering based on the input field.
- Bulk actions: clear all items or clear completed items.
- Local persistence via `localStorage` with safe read/write guards.
- Validation: trim input and prevent duplicate items.
- Alerts for add/update/remove/clear actions.
- Ads consent banner with stored preference; Ad component gated by consent.
- Multi-language UI (English, German, Spanish) with language selector.
- Pages: Home, About, Privacy, plus navigation between pages.
